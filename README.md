# bu-nyan（川合孝次）公式アプリ ポートフォリオLP

Google Play デベロッパー **bu-nyan**（川合孝次）が開発・公開している Android アプリ（全95タイトル）を紹介する公式ポートフォリオ・ランディングページです。

🌐 **Live Demo (GitHub Pages)**: `https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/`

---

## 🌟 主な機能・特徴

- **全95タイトル完全収録**: 公式アイコン、実機スクリーンショット、機能ハイライト、詳細説明文、Google Play公式リンクを網羅。
- **マルチカテゴリ・フィルター**:
  - 🚙 全国巡礼＆マップ（道の駅、ダムカード、百名城、百名山、お遍路、ライブカメラ等）
  - 🛠️ 便利ツール＆日課（電卓、ライト、QRリーダー、電力メーター、Moment Days、価格比較等）
  - 🧩 パズル＆脳トレ（上海、四川省、Flash暗算、2048、LightsOut、ナンプレ等）
  - 🎮 ゲーム＆息抜き（神経衰弱、リバーシ、ソリティア、ダーツ、シューティング等）
  - 🏃 健康＆ウェルネス（Stride Flow、花暦）
- **高速インクリメンタル検索**: アプリ名、キャッチコピー、タグ、説明文からリアルタイムに瞬時絞り込み。
- **柔軟なソート機能**: おすすめ順、高評価順、ダウンロード数順、名前順の並び替え。
- **詳細モーダルビュー**: アプリごとの実機スクリーンショット横スクロールカルーセルと詳細解説。
- **ダークモード / ライトモード対応**: ワンクリックでテーマ切り替え、設定の自動保存。
- **完全レスポンシブ**: スマートフォン・タブレット・PCのあらゆる画面サイズに最適化。

## 📂 ディレクトリ構成

```text
├── index.html          # メインページ HTML
├── css/
│   └── style.css       # スタイルシート（レスポンシブ・ダーク/ライト対応）
├── js/
│   └── app.js          # アプリケーションロジック（フィルタ、検索、モーダル等）
├── assets/
│   ├── apps.json       # アプリ詳細メタデータ JSON（全95タイトル）
│   └── data.js         # クライアント直接読込用データスクリプト
└── task.md             # 画面仕様書および進捗タスクリスト
```

## 🚀 ローカル起動方法

静的Webサイト（HTML/CSS/Vanilla JS）のため、ビルド作業なしでそのままブラウザで開くか、ローカルサーバーで起動できます。

```bash
# Python 3 の簡易HTTPサーバーを使用する場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` にアクセスしてください。
